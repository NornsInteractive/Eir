## 核心原则概述 / Core Privacy Principles

| 维度 / Dimension | 说明 / Description |
| :--- | :--- |
| **免账户体系 / Account-Free** | 无需注册账号、不绑定手机号、邮箱或社交账号。即开即用。<br>No registration, no accounts, no phone numbers, no social logins. |
| **零云端媒体存储 / Zero Cloud Media** | 播放的本地音视频与投屏内容绝不上传至任何中心化云端服务器或数据库，纯端到端（P2P）直传。<br>Local videos and screen casting are streamed purely P2P via WebRTC without touching cloud storage. |
| **无广告与追踪 / No Ads or Tracking** | 坚决不集成任何第三方商业广告 SDK 或行为画像分析 SDK。<br>Completely free of commercial advertising SDKs and tracking analytics. |
| **端到端高强度加密 / End-to-End Encryption** | WebRTC 媒体流与数据信道默认采用标准 DTLS-SRTP 国际安全标准加密。<br>All media and data streams are encrypted using DTLS-SRTP. |
| **随时清空与注销 / Full User Control** | 用户可随时在设置中一键清空房间历史和缓存，卸载即可彻底清除所有本地数据。<br>Purge local room history at any time in Settings; uninstalling clears all data. |
