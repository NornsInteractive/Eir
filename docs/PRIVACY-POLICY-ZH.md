## 欢迎使用 Eir

Norns Interactive（以下简称“我们”）深知个人信息对您的重要性，并始终致力于保护用户的隐私安全。Eir 是一款专注于异地同步观影与 60 FPS 实时屏幕共享的跨平台客户端工具。

我们秉持**“数据最小化”、“零云端留存”与“端到端点对点传输（P2P）”**的核心设计原则。本隐私政策旨在向您清晰、详尽地说明在您使用 Eir 的各项功能时，我们如何处理您的信息、申请的系统权限及其使用目的，以及您所享有的权利。

请在开启或使用 Eir 之前仔细阅读本隐私政策。一旦您使用或继续使用我们的服务，即表示您已充分理解并同意本政策的全部内容。

## 一、我们如何收集与使用您的信息

Eir 采用去中心化、免账户体系架构，**我们不会要求您注册账号、绑定手机号码、提供真实姓名、身份证件号或支付信息**。在您使用本应用的过程中，我们处理的信息范围如下：

### 1. 本地音视频媒体与文件
- **处理方式**：当您在放映室中选择播放本地视频或音频时，Eir 仅通过系统文件选择器读取您主动选取的本地文件数据流。
- **零云端存储**：所选音视频文件在播放过程中**绝不会上传至任何中心化云端服务器或数据库**。在房间内同步播放时，媒体流直接通过 WebRTC / 本地局域网 P2P 加密通道在您与受邀好友的设备间点对点传输。

### 2. 实时屏幕共享数据
- **处理方式**：当您作为主播主动开启投屏共享时，系统将捕获您指定的屏幕、应用视窗或系统伴音，并在本地编码为视频/音频帧后直接通过 WebRTC P2P 通道发送至同房间的观众。
- **零存储保证**：我们不会对您的屏幕捕获画面、投屏内容进行任何形式的录制、抓取、分析或在服务端保存。投屏结束即刻销毁所有临时缓冲区。

### 3. 双向语音连麦与对讲
- **处理方式**：当您主动开启房间对讲麦克风时，Eir 会采集音频信号并通过 WebRTC 进行端到端安全传输（采用 DTLS-SRTP 国际标准协议）。
- **零录音留存**：我们不收集、不录制、不转写亦不留存您的任何语音通讯内容。

### 4. 房间信令与临时交互数据
- **房间码与会话令牌**：为了建立点对点通信链路，客户端会通过边缘信令服务（`wss://eir.norns.cc.cd/ws`）临时交换 6 位数字房间码、会话随机 UUID、WebRTC SDP 及 ICE 网络候选地址。此类信令为内存临时状态，房间关闭或成员断开后**自动即时销毁**。
- **弹幕与房间聊天**：房间内的聊天消息与弹幕通过点对点数据通道（WebRTC DataChannel）或临时信令在参与者之间即时广播，**不设云端历史记录存储**，退出房间后即行清空。
- **本地历史与配置**：应用仅在您的设备本地存储必要的配置（如语言偏好、明暗主题色、最近加入的房间列表缓存）。此类数据存储在您设备的私有沙盒内，您可以随时在应用设置中一键清空。

### 5. 我们坚决不收集的信息
- ❌ **绝无广告追踪**：无任何第三方商业广告 SDK。
- ❌ **绝无行为画像**：不收集您的浏览历史、应用使用习惯或构建用户画像。
- ❌ **绝无敏感设备标识**：不读取设备 IMEI、IMSI、ICCID、MAC 地址或硬件序列号。
- ❌ **绝无地理位置追踪**：不调用 GPS 或精细基站定位权限。

为了向您提供跨平台同步观影与屏幕共享功能，Eir 会在必要时向您申请以下系统权限。我们在申请前均会向您展示明确的提示，并在获得您的明示同意后方开启；您可随时在系统设置中撤回授权。

| 权限名称 / 标识 | 对应平台 | 使用场景与业务目的 | 是否必要 |

| **屏幕录制 / 投屏权限**<br>`MEDIA_PROJECTION` | Android / 桌面 / Web | 仅在您主动发起屏幕共享时由操作系统弹出系统级投屏确认框，用于将您的屏幕画面实时传输给同房间好友。 | 否（仅投屏发起方依赖） |
| **媒体与视频访问权限**<br>`READ_MEDIA_VIDEO` / `READ_EXTERNAL_STORAGE` | Android / 移动端 | 仅在您主动在放映室点击“添加本地视频”时，供系统文件选择器读取您指定的视频文件。 | 否（仅本地观影依赖） |

## 三、第三方服务与数据共享

1. **零第三方分析与广告 SDK**：Eir 不集成任何第三方商业广告平台（如 AdMob、穿山甲）、用户行为分析 SDK（如友盟、TalkingData）或社交登录 SDK。
2. **NAT 穿透中继基础设施（STUN / TURN）**：
   - 当两台设备处于复杂的双重对称 NAT 或防火墙网络下无法建立直接 P2P 连接时，系统会经由标准的 TURN 中继集群（部署在 `ip.norns.cc.cd`）中转媒体数据包。
   - 所有中转数据包均受 WebRTC 标准 DTLS-SRTP 协议端到端加密保护，中继节点仅执行二进制流量转发，**中继服务器在任何情况下均无法解密或窥探其中的视听内容**，亦不保留任何流量数据。
3. **数据不外泄原则**：除依据法律法规或政府强制要求外，我们不会将您的任何信息出售、出租、共享或披露给任何第三方商业机构。

## 四、数据安全保护措施

1. **传输层加密**：所有 Web 客户端通信、信令交互均强制使用 TLS 1.3 / WSS 高强度加密传输。
2. **端到端音视频加密**：WebRTC 媒体信道与数据信道默认采用标准 DTLS 与 SRTP 加密，密钥由双方客户端协商生成，第三方无法监听。
3. **远程配置安全**：系统采用 AES-256-GCM 高强度对称算法对下发的服务端点及 TURN 密钥凭据进行端到端加密保护，杜绝中间人篡改。
4. **本地沙盒隔离**：移动端与桌面端的数据均存储在操作系统隔离的应用私有沙盒内，其他应用程序无权直接读取。

## 五、您的权利与控制权

根据适用的个人信息保护法律法规，您对自己的个人信息享有充分的控制权：

1. **免注册与无痕使用**：您无需注册账户即可体验全部功能。会话结束后，信令服务器不保留任何通信关系。
2. **撤回权限**：您可以随时在您设备的“系统设置 -> 应用管理 -> Eir -> 权限管理”中关闭麦克风、存储、悬浮窗或通知权限。
3. **一键清理本地缓存**：您可以在 Eir 应用内“设置 -> 存储与缓存”中随时点击“清空房间历史”或“重置所有配置”，彻底删除保存在本机设备上的所有临时数据。
4. **注销与数据清除**：由于 Eir 不设立中心化云端用户账户系统，当您从设备上卸载本应用时，本应用在您设备上生成的所有本地数据、缓存及配置文件将一并被系统彻底删除。
